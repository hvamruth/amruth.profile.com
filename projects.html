PROJECT_01 CTF / LABS

Hack The Box

Hack The Box CTF Project

This project involves solving Capture The Flag (CTF) challenges on Hack The Box, a cybersecurity training platform for developing penetration testing, reverse engineering, and problem-solving skills.

The learning process focuses on discovering vulnerabilities in authorized lab environments, understanding exploitation techniques, and completing challenges by capturing flags.

Key Project Components

  • Challenge Variety: Web exploitation, cryptography, binary exploitation, digital forensics, and more.
  • Tools and Techniques: Nmap, Burp Suite, Metasploit, Wireshark, and custom scripts where appropriate.
  • Documentation: Recording methodologies, investigation steps, findings, and lessons learned.
  • Skill Development: Linux fundamentals, privilege escalation, network security, and vulnerability assessment.

Technologies & Skills

Nmap Burp Suite Metasploit Wireshark Linux Penetration Testing

Project Outcome: Builds practical problem-solving abilities, analytical thinking, and foundational penetration-testing skills for cybersecurity roles.

PROJECT_02 LEARNING / CTF

PicoCTF

Cybersecurity Learning & CTF Challenges

PicoCTF is a cybersecurity education platform developed by Carnegie Mellon University's cybersecurity community. It provides hands-on Capture The Flag challenges that help learners understand security concepts through practical problem-solving.

This project explores different challenge categories to develop analytical thinking, technical knowledge, and familiarity with common cybersecurity techniques.

Challenge Categories

  • Cryptography: Decoding messages and learning encryption fundamentals.
  • Reverse Engineering: Analyzing programs to understand their behavior and logic.
  • Web Exploitation: Studying web vulnerabilities and secure application behavior.
  • Binary Exploitation: Learning about memory, program execution, and software vulnerabilities.
  • Digital Forensics: Examining files and digital artifacts to identify hidden information.
  • General Skills: Practicing Linux commands, scripting, encoding, and network protocols.

Skills Developed

Python Linux CLI Cryptography Forensics Web Security Reverse Engineering

Project Outcome: Develops cybersecurity fundamentals through structured challenges and encourages continuous learning in ethical hacking and information security.

PROJECT_03 CAPSTONE / INCIDENT RESPONSE

Capstone Project on Phishing Attack Investigation

Breach Report — Official Instagram Account Compromise

Program: Network Security and Ethical Hacking

This capstone project examines a phishing incident involving the compromise of an organization's official Instagram account. It focuses on understanding social engineering, unauthorized account access, compromised credentials, and the loss of administrative control.

The project applies cybersecurity principles to a structured incident investigation, documenting the potential attack vector, identifying security gaps, and recommending measures to reduce the risk of future incidents.

// OBJECTIVES

  • Investigate the suspected phishing campaign and its attack vector.
  • Reconstruct the reported incident using available evidence.
  • Assess gaps in account security, including two-factor authentication.
  • Identify containment, recovery, and account protection measures.

// SCOPE OF WORK

  • Incident Analysis: Examine the reported phishing activity and available evidence.
  • Attack Reconstruction: Understand how credentials may have been compromised.
  • Vulnerability Assessment: Review authentication and email security controls.
  • Incident Response: Document account recovery and containment procedures.

// TOOLS & TECHNIQUES

  • Email header analysis
  • Phishing URL verification
  • Credential recovery procedures
  • Meta Business Suite and official account recovery resources
  • Cyber hygiene and security awareness

// SECURITY RECOMMENDATIONS

  • Enable multi-factor authentication and secure recovery methods.
  • Conduct phishing awareness training and authorized simulations.
  • Strengthen email filtering and suspicious-link verification.
  • Review administrator access, account recovery settings, and security notifications.

Expected Outcomes

  • Improved understanding of phishing attacks and social engineering.
  • Practical incident documentation and response planning skills.
  • Better awareness of account security and organizational cybersecurity policies.
  • Knowledge of preventive controls and recovery procedures for online business accounts.

Technical Focus

Phishing Analysis Email Security Incident Response Social Engineering MFA Digital Investigation

SECURITY & ETHICS

This project is intended for educational and defensive security purposes. Account investigations and recovery activities should be conducted only with proper authorization. No real credentials or private account information should be disclosed in public reports.
