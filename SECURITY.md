# Security Policy

## 1. Introduction

This website is hosted using GitHub Pages and maintained as a personal project. The security of the website and its visitors is taken seriously. This policy outlines how security vulnerabilities can be reported and how they will be handled.

## 2. Supported Versions

Only the latest version of this website hosted in the main branch of the repository is actively maintained and supported for security updates.

| Version        | Supported |
| -------------- | --------- |
| Latest         | Yes       |
| Older Versions | No        |

## 3. Reporting a Vulnerability

If you discover a security vulnerability or potential security issue on this website, please report it responsibly.

Please include the following information in your report:

* Description of the vulnerability
* Steps to reproduce the issue
* Potential impact
* Screenshots or proof-of-concept (if applicable)

Security reports can be submitted through:

* GitHub Issues in this repository
* Direct message via repository contact information

Do not publicly disclose the vulnerability until it has been reviewed and resolved.

## 4. Response Process

All security reports will be reviewed as soon as possible. If the issue is confirmed, appropriate steps will be taken to resolve the vulnerability, which may include:

* Updating or patching the affected code
* Removing vulnerable components
* Deploying security improvements

Users will be informed when the issue has been resolved.

## 5. Website Security Measures

The website implements the following security practices:

* HTTPS encryption provided by GitHub Pages
* Repository access restricted to authorized maintainers
* Two-factor authentication for repository access
* Regular review of website code and dependencies
* Avoidance of sensitive data storage in the repository

## 6. Third-Party Services

This website may include third-party services such as analytics, embedded media, or external libraries. These services are governed by their own security and privacy policies.

## 7. Responsible Disclosure

Responsible disclosure is encouraged. Individuals reporting vulnerabilities in good faith will not face any legal action and will be acknowledged for helping improve the security of this project.

## 8. Policy Updates

This security policy may be updated periodically to reflect improvements in security practices or changes to the website infrastructure.
